# ChatGPT / Codex、WorkBuddy、飞书的使用方式

这些平台的共同要求是：接手助手能读所选 skill 的本地目录，执行 Python 和本机 SHELX/PLATON，读取输出，并具有所需网络及报告排版能力。先做本机 doctor 验收。仅上传说明文档不等于已经连接到安装了晶体学软件的电脑。

## ChatGPT / GPT、Codex

在具备本机文件和程序工具的环境里，将完整目录交给助手，使用 `交接说明.md` 中的启动文字。可按所用产品的技能导入方式选择单语言包；完整安装资料仍保留在本包根目录。如果当前会话只有云端文件分析能力，先接入能执行本机程序的执行环境；不要让助手声称已调用它无法访问的软件。

标准 skill 是 SKILL.md 加 scripts/references 等资源目录，具体可用能力与部署环境有关。官方资料：[OpenAI 技能说明](https://learn.chatgpt.com/docs/build-skills)。

## WorkBuddy

先完成本包 INSTALL.md 的依赖和本机 profile。支持本地技能导入的客户端可在“添加技能→上传技能”选择 `Cairystal-zh-CN.skill.zip` 或 `Cairystal-en.skill.zip`；如果客户端不接受嵌套压缩包，先解压总包再选择其中的单语言包。也可将已解压的所选 skill 文件夹交给具备本地执行能力的助手。安装后把本机 profile 路径提供给它，不复制作者的配置。

“技能导入成功”只代表指令资源导入；SHELX、PLATON及其运行许可仍需本机配置。官方资料：[WorkBuddy 技能与上传说明](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)。

## 飞书

本包可以作为文件在飞书中发送、下载。若使用飞书里的智能助手，需确认它背后已连接有本地文件/命令执行能力的Windows执行端，才可运行同一套脚本。把包、启动文字和执行端的实际数据路径交给该助手。

若计划自行开发飞书机器人，需要另配消息接收、认证、任务队列/执行端与结果文件返回；本包没有内置飞书Bot、应用凭据或现成MCP服务，也没有在你的飞书账户创建或安装应用。消息接口可参考[飞书接收消息事件](https://open.feishu.cn/document/server-docs/im-v1/message/events/receive)。这是接入路径，尚未完成平台端到端认证。

## 最简单的客户提示

> 请使用 Cairystal 处理这个目录：……。可能元素包括……（含溶剂、反离子），预期二维结构可以附图。晶体信息为“绿色，块状，0.050 × 0.051 × 0.052 mm”。已有配套实验记录时优先读取，缺项一次列出。请保留输入和前后版本，最终提供 CIF、官网 checkCIF PDF、中英文 Word。官网上传按本例明确授权执行。

正式样品不要照抄上面的颜色、尺寸和元素；示例只是填写格式。平台权限或软件环境不能满足时，报告缺失能力，不伪造运行结果。

English: Use the complete selected-language skill with an agent that can access the Windows execution host. Importing instructions does not install SHELX/PLATON or establish a local connection. The package includes setup, integrity checks and handoff instructions, but no native Feishu bot or universal host integration. WorkBuddy and Feishu end-to-end compatibility has not been certified in this run.
