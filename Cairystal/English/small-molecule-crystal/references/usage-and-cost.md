# 按证据减少重复工作

化学合理性和本次衍射证据优先。工具按本例问题调用，不逐个运行整个工具箱。没有 A/B 也不能据此省去初解元素、连接、占有率、氢和模型复核。

- A/B 全部是已识别的实验元数据缺项时，`ab-auto` 在完成文件配对、原生精修检查和本地 CHK 指纹核验后，直接输出缺项与对应工具；不再复制一套坐标、扫描全部原子邻域或建立不会执行的结构试修计划。警告继续保留。任何混合、未知或结构相关 A/B 都走原有完整诊断。
- 同一任务的 `deliver continue` 自动尝试复用上一尝试的报表页面；不会搜索其它案例或旧答案。也可在 `deliver run` 明确传 `--render-cache SAME_JOB_QA`。旧版没有复用凭据的页面仍重新渲染。
- 复用只忽略 DOCX ZIP 容器的时间戳；文档中每个内容部件都比较 SHA256，包括格式、图片和文字。检查 Word、PowerShell、Poppler 和渲染代码指纹，以及字体文件清单/大小/时间、模板和相关设置。含动态域或外部关系、环境不能核验、文件缺失或页面校验失败时重新渲染。字体文件的属性检查是普通本机缓存失效信号，不是对操作系统的密码学认证。
- PDF、所有页面 PNG 的 SHA256 与页数必须完整。复用后仍检查中英文数值、PDF 字形、表格越界、正文缺失和文件绑定；不是“AI 已逐页看过”的声明。结构改变、警告或报表解释改变均会令文档内容指纹失配。
- 官网报告仍以最终 CIF 指纹和完整回执匹配；页面复用不替代官网验证、不复用科学结论，也不改变已授权数据范围。
- SHELXD、特殊位置、无序、孪晶、SQUEEZE 等分支不能仅因使用少而删除。短小的输入/化学一致性检查通常远小于求解和报告耗时，不为毫秒级收益增加复杂缓存。

用 `performance --run DELIVERY_RUN` 分开查看首次渲染、页面复用和排版检查耗时。分阶段的重放测试不能宣称整颗晶体从头解析快了相同比例。没有真实 Token 计数时填未知。

维护测试从固定版入口运行；避免在含同名旧脚本的项目根目录直接 `import`。便携测试入口设置子进程 UTF-8，防止中文 CLI JSON 被系统默认编码误读。原模型、原始 HKL 与历史报告均保留。
