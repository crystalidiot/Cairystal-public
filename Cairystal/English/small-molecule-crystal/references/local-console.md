# 本地可视化工作台

用于查看真实任务记录、解释步骤状态、保存新参数方案，以及显式启动新任务。第一版界面为中文；英文入口文档同时提供。稳定版解析程序与判定规则不变。

## 使用
使用本机 profile 所配置的 Python 执行：

    python -B scripts/toolbox.py run console -- --workspace WORKSPACE --profile PROFILE.json --open

WORKSPACE 是 skill 和原始输入以外的新目录。界面仅监听本机 127.0.0.1，默认 8765 端口；端口冲突可用 --port 0 自动分配。运行输出给出实际网址。普通客户无需 Node，前端已打包；Python 与本机科学软件仍按安装指南配置。

1. “登记已有任务”接受明确指定、包含 result.json / pipeline.json / autorun.json 的运行文件夹。仅有原始 HKL 时，使用“方案与参数”。不会自动搜索磁盘。
2. 客户视图看流程、A/B 警告、已有结构查看器与四项交付；作者视图展开每步的证据和配置。
3. 填写两组资料：所有可能元素（包括溶剂和反离子，可附二维图片），以及颜色 / 形状 / 尺寸。未确认的外观只保存草稿。二维图片本地保存，尚未直接自动转为已审核的化学图。
4. 可以调整候选数量、权重迭代次数、单次程序超时；数值范围与底层脚本一致。保存产生新版本，记录差异，不会执行。点击“开始”并确认才运行。
5. 每份方案固定 profile、样品信息和已审核 graph 文件的快照与哈希。改变文件后必须另存。调整同一数据目录的父方案会保留此前图片；更换数据目录时不能继承这张图片。
6. 启动目前支持唯一一组同名 HKL/P4P；其他输入仍用工具箱由 agent 准备。没有已审核二维图或遇到科学歧义时，会按既有流程停在需要判断的位置。界面不代替科学判断。

## 完成与权限
不通过界面默许上传授权。最终 CIF、官网 PDF、中英文 Word 仍遵循原有完整交付要求与原始数据目录/Cairystal 规则；没有取得就显示缺失，不能用本地报告冒充官网 PDF。已有授权由 agent 在原任务按既有流程恢复，无需重复问客户。

## 对照与状态
对照来自每次真实 attempt.json，可比较 R1、wR2、GoF、耗时与警告。相同原始 HKL 哈希不保证 OMIT 或其他处理相同。低 R、零 A/B、文件存在都不是正确解析证明。灰色步骤表示缺乏独立记录；有精修指标但没有通过记录时标为待复核。

拖动流程块只改变布局，不改变执行次序；本版本不提供任意代码节点、任意流程重排、自动采用无序方案或后台上传。布局刷新后恢复默认，不应当作已保存的执行方案。

## 实现与维护
界面不调用语言模型；后台使用既有工具箱。服务没有云依赖，浏览器资源全部本地提供。输入与执行仍由已配置 profile 控制；这不是面向多用户的网络服务器，不开放公网。
前端源文件与固定依赖锁位于 assets/console-source；修改 UI 后重建 assets/console。第三方声明见 licenses/console/NOTICE.md。维护测试入口：scripts/test_crystal_console.py；构建与测试不等于重新求解晶体。
