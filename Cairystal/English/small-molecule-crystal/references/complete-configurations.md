# 完整构型、共享位置与 CIF 占有率

本页补充 `fragment-orbits`，适用于一个完整分子由多颗不等 SOF 的独立原子和对称像共同表示，或分子本身具有特殊对称的情形。它是只读诊断，不生成化学身份或自动接受模型。

## 输入完整分子，避免重复计数

简单模式仍可输入同 SOF 的原子名称列表。复杂情况须明确给出每个完整构型的 `probability`，原子可写为 `{"label":"C1","symmetry":"1-x,y,1-z"}`。该操作必须属于当前 CIF 空间群（允许整数晶格平移）。同一原子名称可以使用多个不同的对称像，但不能把同一物理原子重复放进一个构型。

```json
{"fragments":[{"id":"reviewed_ring","probability":0.5,"atoms":[
  {"label":"C1"},{"label":"C2"},
  {"label":"C1","symmetry":"1-x,y,1-z"},
  {"label":"C3","symmetry":"1-x,y,1-z"},
  {"label":"C4"},{"label":"C3"}
]}]}
```

以上只是输入形式，不是可套用于任意晶体的坐标或概率模板。须先检查当前键长、几何、密度和所需片段是否完整。原子像使用同一完整构型；工具不为每颗原子随意选择最近的晶格像。

工具先合并由分子自身对称产生的重复完整构型，再逐物理位置累加构型概率，并与 SHELX SOF、轨道重数和 CIF 化学占有率交叉核对。共享反心原子的化学占有率可能为 1，而两个分子取向各为 0.5，这是可能正确的。检查最多 64 个空间群操作、128 个唯一完整构型；超范围返回复核，不静默跳过。

## 负 PART 与原生特殊位置

负 PART 不能作为所有特殊位置问题的通用修复。原子恰好在两重轴等特殊位置、同时用负 PART 和手工坐标/ADP 固定时，原生 CIF 导出的占有率可能与几何轨道计数不符。

1. 先判定分子和原子应具有的实际特殊对称，并计算晶胞原子数；保留原模型。
2. 仅对已确认的特殊位置作原生对照，恢复适当的 PART 和自动特殊位置约束，检查实际导出的 CIF。不要直接改 CIF 占有率数字使其过关。
3. **同时处理该原子的实际骑乘 H 标签**，核对 PART、AFIX、SOF 和 H 的轨道重数。不能猜氢名，也不能用字符串前缀选原子（`C9` 与 `C91` 不等价）。`fragment-orbits` 的显式模式会检查所选片段已有骑乘氢的母原子/PART 和 CIF 计数。
4. 共享 `PART 0` 母原子可以连接不同取向的氢；不能把母原子与氢的化学占有率机械设为相同。

## 方案取舍

- 同权重比较几何、NPD、收敛、残余密度及 A/B；最终权重更新单独记账。
- 从特殊位置释放坐标后出现 NPD 或不稳定，而 R1 仅极小下降时，保留更简单的共享位置模型。
- 自由占有率使两个互斥构型各大于 0.5 时，即使 R1 下降，也不能接受；检查成分假设、密度和 ADP，而不是把结果截成 0.5。
- 从刚性环改为限制环后产生不合理平均键长，不能仅凭 R1 降低认为更好。
- 已有模型通过计数与结构检查时允许保持不变。异常反射和缺失实验信息分别记录，不宣称溶剂工具能修复数据问题。
- HKL 的换行或 `000` 终止行可能改变文件哈希。原件照常保留，同时比较终止行前的 h/k/l、Fo²、σ 数组；不要读取或继承未知尾部内容。最终运行优先使用授权原始反射副本。

这些检查只给出必要条件。短接触不自动等于互斥；两/三构型概率界限通过也不证明全局结构正确。实验中发现的工具或选择器失误须单列，不当作科学失败或成功。

依据：[SHELXL 官方 SOF、PART、AFIX 指令](https://shelx.uni-goettingen.de/shelxl_html.php)。
