# 历史案例学习与低上下文诊断（实验功能）

本模块学习“先查哪类问题”，不学习原子坐标，也不训练 GPT、MolScribe 或 SHELX 的神经网络权重。仅在用户授权使用的历史数据上拟合。原始样本、稳定版和旧结果保持只读。

## 已实现

`scripts/case_triage.py` 使用 Python 标准库，无网络和 LLM 调用：

1. 从已完成的当前结果记录生成 `diagnostic_packet.json` / 中文摘要，保留每条 A/B 的代码、级别、原子/反射原文、未知指标、失败原因及完整日志入口。
2. 实验参数缺失与模型/数据问题分列，但不删除警告。当前规则明确覆盖的元数据代码仅 183/184/185/196/197/198/699；其他不认识的代码按待审查处理。
3. 当前警告与 NPD/收敛证据优先决定知识文档入口；242 先检查元素/占有率/无序，不能直接靠 SIMU；934/919 不自动 OMIT；306 不自动把氧认成水。
4. 从历史尝试名称统计每类案例曾用的诊断方向，每例每个方向最多计一次，避免重复失败试验将某方案权重无限抬高。按类别的计数用全体频率作平滑，前三项仅辅助排序。
5. 没有 A/B 但模型不完整、指标缺失、NPD、未收敛、未知警告或原生程序失败，仍返回待审查。不自动接受结构、不修改原子、元素、空间群、限制或反射。

历史诊断频率不是“成功率”，历史上尝试过不代表应该尝试。新先验不会自动代替已稳定的 `crystal_autorun.py`；仍保留该调度器现有 `handoff.json`。这是显式调用的独立诊断工具，避免把小样本排序强行塞进生产流程。

## 使用

在当前运行目录里产生规范化结果记录：`case_id`、已知 `category`（未知写 null，不从晶胞猜身份）、`status`、`metrics`、逐条 `major_alerts`、`unresolved`、`failure_analysis`、`official_iucr_report`。指标缺失写 null。输入状态不能仅由 R1 或 A/B 数量生成。

```powershell
python scripts/case_triage.py triage --record CURRENT_RUN/result.json --prior references/diagnostic_route_prior.json --output CURRENT_RUN/diagnostic_packet.json
```

程序在终端打印中文摘要，JSON 留存全部路由证据。输出必须为新路径，不覆盖旧记录。先读此摘要和本轮 `handoff.json`，再按需读对应日志/原子表，避免一次装入整个历史 JSON。

重新拟合只在另建实验版、取得训练数据授权后使用：

```powershell
python scripts/case_triage.py fit --training AUTHORIZED_TRAINING.json --output NEW_PRIOR.json
```

训练文件包含 `cases` 数组。每条至少有 `category`、`trials` 和可选 `round_trials`，尝试项的 `name` 用作弱标签。先固定训练/评价划分，冻结脚本和先验哈希，再揭示评价历史；不根据评价结果反复调参后仍称独立测试。此工具不读取参考 CIF 或 RES。

## 本轮证据与边界

2026-10-28 的回顾性工程实验使用 11 类共 55 例，每类 4 例训练、1 例评价；44/11。旧记录中 41 例标为候选完成、12 例部分模型、2 例精修失败，并非 41 例经答案确认正确。训练材料包含未完善模型，不能用作原子指认的金标准。

- 55 例共 470 条历史 A/B，在摘要中逐实例原样保留。
- `o200k_base` 代理分词：完整历史 JSON 共 429971 token，诊断摘要 91013，少 78.83%。评价 11 例为 93356 → 19646，少 78.96%。这只是所选文本的长度对比；不是 GPT-6 的精确计费，也不是整段对话、总推理 token 或完整流程耗时节省率。现有流程若已使用短摘要，额外收益会更小。
- 评价集的历史诊断方向共 42 个。通用频率前三项覆盖 21 个，类别先验覆盖 23 个。标签来自历史尝试，不是专家确认的正确路线；改善很有限，不能据此宣称结构解析准确率提高。
- 11 例复制历史候选 RES 继续运行 SHELXL，并重新验证原有配套 CIF/FCF，A/B 11/11 重现。这是可重复性检查，**不是从 HKL 独立重解**。新原生输出仅为实验中间文件，不替代已交付结构。
- 本轮没有重新生成 IUCr 官网报告或 Word，因为没有接受新的最终结构。正式结构交付仍必须经过原有化学审查、精修、完整 A/B、配套文件、官网验证和中英文 Word；本地 PLATON/摘要不能替代官网报告。

## 从失败记录保留下来的实践

- 把数据读取、版本、权重、模型选择、元数据和报告整理分开计时。原生程序很快不代表整个任务快；反之不能把 AI 时间全部归因于软件。
- C/N/O 指认需要二维连接、电荷/氢数和本轮密度交叉验证；历史最常见元素或最低 R 不是确定答案。多次弱区溶剂、特殊位置和无序试验无结论时，给出明确的不确定范围及失败对照，不重复相同无证据假设。
- 将水氢和一般骑乘氢分开：几何批量加氢适用于已确定母原子和化学状态；水身份、方向、质子化仍需证据。
- 权重优化、热参数限制和 OMIT 是不同试验轴。不得以 GoF 靠近 1、A/B 降级或等向精修掩盖错误元素、无序或占有率。
- 部分模型即使数值收敛也保持部分模型；指标为 null 不得填 0。保留结构类和实验缺参类警告的完整分列。
- 这里的先验已经接触过这批 55 例中的训练子集。以后使用同一批数据测试必须披露训练重叠，不能称为全新盲测。真正检验未知结构能力需要新来源、无训练重叠的数据。

进一步科学诊断使用已有 `ab-alert-action-playbook.md`、`chemical-model-and-density.md`、`disorder-occupancy.md`、`adp-model-selection.md`、`nonconvergence.md`。文档知识和频率排序均不等于自动修复能力。
