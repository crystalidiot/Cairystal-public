# A/B 实测后的配对与比较规则

这些判断由脚本执行，常规情况不需要 agent 重读完整日志。入口仍为 `autorun` / `complete`；自动修复仍须保留对照并验证。

1. **晶胞配对**：`crystal_runtime.compare_cell_tokens` 按数值显示的末位舍入检查 CIF/FCF，保存差值及容许舍入量。括号中的标准不确定度不是匹配容差。HKL、内嵌 RES、原子坐标、空间群、反射数等检查照常执行；晶胞近似相等不能证明样品相同。
2. **比较警告**：`compare_diagnostic_trials` 保留每次警告，包括重复项。213/214/234 的相同原子、级别、类型及上下文只改变数值时，记入 `value_changed`，不算新增或消除；不同原子/PART 后缀、级别或对称上下文仍分开。未知格式不宽泛删除数字。数值改善但仍报警，不能算解决。
3. **实验参数继承**：候选只能在 HKL 和 CELL/空间群控制不变时继承同一次实验的字段。晶胞六参数与 `_cell_volume` 一起保留原始精度；原体积未知时保持未知，不继承占位 ZERR 产生的假精度。不得借此复制原子模型或参考答案。
4. **验证失败**：超时、缺失完成标记或解析冲突时，`validation_complete=false`，`validated_counts=null`，`alerts=null`；不完整输出留在 `partial_parse`，失败原因和输入哈希照常保存。不得把空文件/零解析条数当作零 A/B。候选失败可继续其他独立候选；共同对照失败停止无效重复。
5. **指认与无序**：241/242 涉及满占有原子，但其成键邻居有 PART/部分占有时，先交给无序模型比较，不单凭 Ueq 自动做元素扫描。不是确认原指认正确；明确化学或密度证据仍可通过 `repair-plan` 单独比较。
6. **双语报表**：新节采用标题的 `page_break_before`，避免独立分页段落产生空页。`report-qa` 按正文区域识别空白页，页码/页脚不算正文；图片或矢量图仍视为内容。始终检查中英文数表一致、原文保留及渲染页面。官网 PDF 仅可复用同一字节哈希 CIF 的真实验证；改模型后重新验证。

本次四例仅验证既有工作模型上的工程行为；不属于新的盲解，也未对参考答案评分。仍需 AI/专家处理无序拓扑、可疑化学指认、缺少证据的水氢和未解决警告。
