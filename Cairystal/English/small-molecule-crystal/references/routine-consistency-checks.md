# 无 AI 的常规一致性检查与 A/B 对照

以下脚本只读输入，输出到新目录；不改元素、坐标、占有率、实验参数或反射。通过规则不等于结构正确。仅导入现有 Python/Gemmi 依赖，不调用模型 API。

## CIF 与指令检查

```powershell
python scripts/routine_consistency.py --cif <本次模型.cif> --res <本次模型.res> --output <新的检查目录>
```

`--res` 可省略：若 CIF 有内嵌 RES，就检查内嵌文本；没有则明确标记指令未检查。不会跟随 include 文件读取其他路径。原始文件哈希前后核对。输出 `routine_consistency.json` 与中文 `检查摘要.txt`。

| 自动工作 | 范围与限制 |
|---|---|
| 分子式 → 元素数、分子量 | 简单 CIF sum formula，支持小数计数与 D；括号、加合物、带电或其他复杂表示交回复核，不能猜 |
| a/b/c/角度 → 晶胞体积 | 检查正定度量及体积一致性，不决定空间群 |
| Mr/Z/V → 计算密度 | 不混同实测密度；不自动覆盖原值 |
| 电子计数 → F(000) 初筛 | 按中性原子约定；掩膜/特殊散射项或数值不符需要解释，不直接证明错原子 |
| EXTI/SWAT、LIST/ACTA | 识别冲突；ACTA 无显式 LIST 时认可隐含 LIST 4 |
| OMIT 清单 | 区分显式 hkl 与阈值/角度形式，报告字面重复；不合并对称等价指标，也不计算完整度或删点 |
| SAME 中氢与映射提示 | 根据简单 SFAC 的实际原子记录识别 H/D；不自动确认化学等价映射或展开复杂残基 |

忽略 END 后的建议指令、注释和独立缩进说明，识别续行。输出数值容差是公开的筛查阈值，不是实验标准不确定度；全部计算和比较差值保留在 JSON。未知字段保留 null，不填 0。

退出码：0 = 所执行检查未发现问题；1 = 明确矛盾/解析失败；2 = 有待复核事项。`checks_passed` 不是化学接受结论，没供应 RES 的命令也不能称指令已通过。

## 已接入的流程

`paired_bundle` 返回 `routine_checks`，复用已有文件配对流程；`scientific_report_rules` 的自动复核、`routine_finish` 的输入和最终候选、`crystal_delivery` 的最终提交前均使用检查结果。

明确数值矛盾或 EXTI/SWAT 冲突会在官网提交/报表生成前停止，并保存 `routine_consistency.json`。限定范围的自动接受还会因未决检查停止；人工已复核路线允许带记录的待复核信息继续交付，但不会把它标为已解决。最终完整审计记录保留结果。本功能不替代已有占有率/配套文件核查、本地 PLATON、IUCr 官网验证或中英文报告 QA。

## A/B 警告前后对比

```powershell
python scripts/compare_ab_alerts.py --before <修改前报告文本> --after <修改后报告文本> --output <新的对照目录>
```

只传明确指定的本次文件：支持本地 `.chk` 或已保存的 IUCr `official_text.txt`，不扫描历史结果。输入必须带一致的警告汇总；截断、计数不符、本地/官网范围混用都会拒绝。它不提交官网、不读 PDF，也不独立认证报告对应哪份 CIF。

输出 `ab_comparison.json` 和中文 `index.html`。保留同代码多条警告，按完整原文的多重集合对比“前有后无 / 后新增或变化 / 完全相同”，并列出代码在前后 A/B/C/G 的数量。数值、标签或等级变化可能同时列入两边；不能把“前有后无”自动称为科学问题解决。展示内容进行 HTML 转义。

## 实测范围

新增合成测试覆盖数值矛盾、未知/复杂公式、掩膜约定、指令续行/注释/END、重复 OMIT、水氢、截断报告、重复警告、中文路径、只读输入、禁止覆盖输出及交付停止位置。实际执行了正确模型、错误密度和 A/B 对比三个 CLI 示例，原文件哈希一致。示例是合成数据，不是新解析晶体，也不证明总体流程提速比例或 Token 节省量。
