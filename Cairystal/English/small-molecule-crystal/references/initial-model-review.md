# 第 02 步：初解候选检查与轻原子指认

SHELXT 产生的是候选，不是“已经准确解析的结构”。先短程 SHELXL 精修取得可配对的 CIF/RES，再筛查元素、连接、ADP、占有率与密度；通过的是“值得继续处理”，不是最终科学认可。

## 已执行的部分

新版本 `crystal_session.start` 对每个初解后的基线调用 `initial_model_review.py`，保存 `initial_review.json`；候选摘要、决策包保留文件路径、哈希和状态。检查失败记录 `review_unavailable`，自动流程交回处理，不把失败当完成。

独立调用（仅读取当前候选的 CIF/RES 及同名 LST/CHK）：

    python -B scripts/toolbox.py run initial-review -- --directory CURRENT_CANDIDATE --stem model --elements C N O Cl --output NEW_REVIEW.json
    python -B scripts/toolbox.py run route-problem -- --initial-review NEW_REVIEW.json

工具列出所有 C/N/O 位点的实际散射类型、PART、占有率、近邻距离/角度、可比较近邻 Ueq、差值峰线索和初筛标记。它不更改坐标/元素、不补氢、不上传；几何阈值是筛查提示，不能冒充 checkCIF 阈值。没有 CIF 时应先完成本次原生基线，不能伪造 CIF 或从旧模型借用。

## 简单判断：四类证据一起看

| 证据 | 首先判断 | 不能直接推定什么 |
|---|---|---|
| SFAC 和连接 | 标签与真正散射类型是否一致；对称展开后的邻接、完整基团、PART 是否合理 | 名字 C1 不代表按 C 精修；两个近点不一定成键 |
| 价态、键长和角度 | 结合二维图/当前连接判断键级、可能的 C/N/O、质子化及电荷 | 芳香 C/N、酰胺 N、羰基 O 等不能凭一条长度唯一判定；配位与超价情况需另查 |
| 相邻 ADP | 比较同环境、相近占有率的非氢近邻；先分清本位点偏低还是邻居异常高 | Ueq 偏小可能指认过轻，偏大可能过重，但运动、无序、占有率和数据误差也会补偿 |
| 局部正负残差 | 检查该位点及周边本次差值密度；过轻常伴正残差，过重可能伴负残差 | Q 峰列表不含完整正负地图；全局最大/最小值不能代替该位点的密度 |

以上是诊断线索。C/N/O 相邻原子序数的 X 射线差异有限；几项证据相互冲突时保留多解，不能以“AI 觉得像”定案。官方 PLAT242 也指出低 Ueq 可提示错元素，但末端基团可能产生假阳性。[IUCr PLAT242](https://journals.iucr.org/services/cif/checking/PLAT242.html)

## 怎样做元素对照

1. 仅使用客户允许的元素。元素清单不表示精确配比，未知溶剂或电荷不得由脚本编造。
2. 有已审核完整二维图：使用 `match` 对本次三维候选作受限匹配，并保留 C/N/O 指认方案与对照；现有 matcher 对特殊位置、无序和部分占有率有明确边界。
3. 没有足够二维依据：先读初筛和局部密度，可用 `session refine` 的显式 `variant_site` / `variants` 建立独立元素试验；必须给本次证据原因。原位点坐标来自本次求解，精修比较保持数据、反射选择和初始权重可比。
4. 比较局部连接/价态、电荷、ADP/占有率、差值密度、收敛和全局拟合；不能只因 R1 稍低选择。多个指认仍近似时明确未决。
5. 类型/质子化确定后才生成 H；检查最终 H 数、PART/SOF、UNIT 和化学式。不要用 SIMU 抹平错类型，也不要提前加大量氢使错误化学更难识别。

## 三种结果

- `needs_review`：有具体可疑项。按对应工具分流并记录对照。
- `screened_requires_chemical_review`：所实现的数值筛查未发现标记，仍需检查化学、对称性、模型完整性与局部密度。
- `review_unavailable`：输入/解析/依赖等阻止筛查。保留错误，不能标为“检查通过”。

新脚本只建立初筛和诊断依据；完整无序、水氢方向、空间群唯一性等仍由各专门路线处理。它不输出“结构正确”的自动结论。
