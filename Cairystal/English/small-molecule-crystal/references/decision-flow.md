# 初解决策、停顿记录与分级无序

当前模型检查的 `decision_queue` 将具体原子、证据、工具、参数模板和下一步连起来。先处理文件配对/占有率/几何矛盾，再比较元素指认或无序；没有标志不等于化学正确。队列只引用本次模型，不读取历史答案。

## 初解与元素对照

原来的 `initial-review` 命令保持兼容。新增可选参数：

```text
python -B cairystal.py run initial-review -- --directory CURRENT --stem model --elements C N O Cl --output NEW_REVIEW.json --trial-output NEW_TYPES --profile MACHINE.json --run-trials
```

默认最多检查 2 个可疑位点、4 个单原子替换。`--max-sites` / `--max-trials` 可在帮助给定范围内调整。只比较输入允许且已在 SFAC 中的 C/N/O；不把元素清单当分子式。每次只改变一个原子类型，保留同样反射、空间群和起始权重，生成同轮数未改模型对照，并核算 UNIT。元素候选来源于异常相对 U；这不是元素身份的证明。

`--trial-output` 单独使用只准备；`--run-trials` 才运行 SHELXL 与本地 PLATON，并保存比较。没有可运行候选就列出原因，不重复跑空对照。要求当前完整配对 INS/RES/HKL/CIF/FCF/LST；诊断用的两文件夹不足以启动精修。哈希变化须重新诊断。

已有 H、特殊/部分占有位置、已有 PART、约束冲突或异常几何的自动元素替换会暂缓，助手按具体证据处理。已有 H 的保守暂缓是当前限制，不表示元素不能修改。单纯“未建氢”的信息不阻止初解元素对照，原提示仍保留。化学类型确认后再生成适当的 H。原生对照完成后不能仅凭最低 R、最少 AB 采用模型。

autorun 的 `handoff.json` 保留每个初解候选的完整决策队列，避免只看到前三条发现；已计算的原子详情留在 `initial_review.json`，不用再扫一遍模型。

## 停顿及耗时

新版 autorun 把停顿写入 `wait_episodes`，按元素/连接、候选选择、无序、模型复核、环境执行、报告、上传授权、指纹变化和结果不确定等归类。相同证据的重复观察不会重新起算；实际执行下一步或证据变化时关闭区间。历史任务没有记录则为未知，不倒推。

```text
python -B cairystal.py run performance -- --workflow-run EXACT_AUTORUN_DIR --output NEW_TIMING.json
```

输出关闭区间、尚未结束的区间、重复观察次数、已记录程序动作及前三类停顿。区间含等待、离线工作和助手操作，不是实测 AI 时间；Token 无计数时仍为 null。父流程、子阶段不相加。原 `performance --run DELIVERY_DIR` 用法仍保留。

## 常见无序的分级比较

沿用 `disorder`、`density-disorder`：CF3、叔丁基、已有 sp3/H 依据的烷基链、用户已说明身份的常见溶剂。链的每个末端最多保留三个嵌套末端片段，分别试一个转动轴；不组合无限多扭转。刚体溶剂仍不覆盖环翻转/内部柔性。

先按本次差值峰提出完整片段候选，再短精修，再将少量候选从同一原始基线送入完整精修/PLATON。`promotion_decisions` 逐项记录入选、失败、不完整指标或预算暂缓。短筛 AB 为 null，不称通过验证。低 R 候选若存在短键/几何矛盾，排序先考虑这些问题；排序仅分配后续计算，不确认结构。

没有候选进入完整比较时，保留已有基线和原因，不再白跑一个完整空对照。分裂后缺原子、占有率异常、特殊位置迁移及分支坍合仍须处理；分支距离按周期边界核对。

特殊位置不会套用普通位置的机械分裂。扫描记录稳定子阶数、对应对称操作、物理占有率及 SHELXL 编码，并指向 occupancy 工具。需要据完整分子取向、共享原子及组成作进一步处理。这次增加的是诊断和交接，不宣称自动解决所有特殊位置无序。

所有既有精修、化学优先复核、AB 检查、最终 CIF 对应的官网验证和中英文 Word 要求不变。
