# 特殊位置要核对完整构型

用于原子靠近反心、PART 之间短接触或 CIF 占有率看似“翻倍”的情形。先运行 `occupancy`，再为已确定的完整片段使用 `fragment-orbits`。工具只收集证据，不自动改变占有率或接受模型。

## 三层计数

区分 SHELX 解码 SOF `q`、普通位置重数 `M`、该原子的几何轨道重数 `m`。每晶胞贡献为 `M*q`，CIF 化学占有率为 `M*q/m`。例如反心上的 SOF 0.10 在 P -1 中对应化学占有率 0.20，而不是必然多放了一倍原子。是否合理要看分子整体、共享位置及构型是否能共存，不能机械地除以二。

另一种情形是**整个非中心对称分子在反心附近有两个相反取向**，各原子自身仍在普通位置。若一个分子占据该区域，两个对称取向可各用 SOF 0.5；负 PART 避免人为生成特殊位置约束和对称间成键。不要同时显式复制一套反演原子再保留原空间群，否则可能重复计数。氢必须跟随母原子的 PART 和有效占有率。

SHELXL 的 PART、SOF 和 HFIX 语义见[官方指令手册](https://shelx.uni-goettingen.de/shelxl_html.php)。负 PART 是连接/约束控制，不会自动解决化学上不可能的占有关系。

## 不只看两两占有率

给每个完整构型列原子、同一对称操作、概率及与其他构型的严重接触。若三个构型两两不能同时存在，它们的概率之和也不能超过 1。即使每一对都不超过 1，三者仍可能冲突。`fragment-orbits` 检查由短接触提示的两/三构型占有率上界，使用统一晶格平移，不为每个原子分别挑最近位置。

```json
{"fragments":[{"id":"A","atoms":["C1A","Cl1A","Cl2A"]},{"id":"B","atoms":["C1B","Cl1B","Cl2B"]}],"severe_contact_fraction":0.70}
```

```text
python -B scripts/toolbox.py run fragment-orbits -- --directory CURRENT_PAIRED_BUNDLE --config REVIEWED_FRAGMENTS.json --output NEW_AUDIT.json
```

输入片段须已由当前化学/密度证据确定并聚拢；只选重原子。同 SOF 简单模式不能代表不同 SOF 或分子自身特殊对称；这些情况使用经复核的显式完整构型模式，见 complete-configurations.md。非支持元素或过大片段仍停止。短接触阈值不是普适物理定律，输出需要结合误差和化学解释；通过检查也不是全局占有模型的证明。

把次组分设为 `(1-f)/2` 有时满足局部排斥关系，但若它意味着“两个主组分分子”替换成“一个次组分分子”，就改变了平均溶剂量，必须明确记录该组成假设，不能当作纯粹消警告操作。

## 从错误元素和缺失溶剂中恢复

- 单连接碳的缺氢提示先看价态：若相邻原子已是羰基碳，末端约 1.3 Å 的位点可能是氧。只在几何、热参数和本次精修支持后调整元素；不要直接补甲基氢。
- 两个拟议成键原子异常接近时，先做有记录的去原子差值图。散射相近的“轻原子满占有”和“重原子部分占有”可能混淆；须用完整化学片段、所有对称像和占有率计数检验，不能凭峰高直接决定元素。
- 按当前差值图、键长/键角重建完整取向，再比较各向同性/各向异性方案、NPD、残余密度和收敛。较低 R 但构型不相容的方案不能胜出；保留更简单的模型和未解释密度说明。
- 跨晶胞/反演连接的 CH2 可由原生 HFIX 处理。HFIX 必须放在所有原子之前，随后检查实际生成的 H、母原子、占有率和氢键方向。
- 先在相同权重下比较模型；模型确定后单独运行有记录的权重更新。不能修改原始强度误差来凑 GoF。
- 910 等低角缺失反射提示要核对原 HKL 与 FCF。如果两者都没有这些测量，不得补造强度或用改测角范围伪装为修复。
