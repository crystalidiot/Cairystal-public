# Cairystal

Current priority (2026-11-23): chemical reasonableness with current-data support first, A/B second. Authorized references may assist with recorded provenance; blind restrictions remain unchanged. See [chemical-first selection](chemical-first.en.md).

English edition. Customer instructions and the one-time intake form default to English; both Chinese and English Word reports remain mandatory. See [language selection and scope](language-selection.md) and [getting started / agent handoff](../START.en.md). The executable scientific workflow is identical in both language packages.

Use the scripts for routine work and reason about uncertain science. Read only the relevant reference below; do not load all manuals or worked cases. Script execution, convergence, low R or zero A/B does not prove a correct structure.

## Inputs and invariants

- Gather missing information together using [one-time intake](one-time-intake.md), preferably `intake_once.py form --language en`. Include possible elements from solvent/counterions, available chemistry/2D structure, appearance/dimensions and workflow choices. Give colour/habit options and one combined appearance example: “green, block, 0.050 × 0.051 × 0.052 mm”; examples are hints only, never prefilled observations. Reuse current-specimen facts and authorization. Save unknown optional fields; do not repeatedly ask for colour, habit or size. Only genuinely new blocking conflicts require a consolidated follow-up. Unconfirmed defaults stay in labelled drafts, outside measured CIF fields.
- Preserve raw files and hashes, work in a new directory, retain failed candidates and record the reason for model/data changes. Elements are a set of possibilities, not counts or a formula. Record SFAC order, symmetry/setting, composition hypotheses and processing lineage.
- Respect each task's blind-input scope. No old coordinates, reference identities, literature lookup or worked-case answers during blind solving. Disclose prior conversational exposure. Current-run evidence may be read; models may not be borrowed between cases.
- Prefer headless SHELX/PLATON; do not open Olex2 routinely. Assemble fragments before handoff and normally use LIST 4. Preserve PART/FVAR/special-position accounting. Use [routine twin routing](routine-twin-routing.md): no extra twin search without concrete evidence; supported two-domain HKLF 4 twins use automatic file pairing, and BASF-only batch scales are not classified as twins. Unsupported HKLF 5/other formats, isotope-specific processing, complex chemistry or ambiguous assignments need explicit review.
- Same-experiment metadata is not interchangeable with model-derived numbers. Cell-measurement theta/count differ from refinement theta/count. CIF temperatures are K; TEMP is degrees Celsius. Missing source temperature remains unknown unless the current user explicitly authorized the bounded [room-temperature convention](user-temperature-default.md). Check permitted original records and conflicts first, and disclose any adopted value as an assumption in the CIF and both reports, never as an instrument measurement. Do not unconditionally replace cell-measurement temperature with a user-provided diffraction temperature.
- For explicitly supplied anonymized experimental sidecars use [the seven-field import bridge](anonymous-experimental-sidecars.md). Validate case and input hashes, retain both temperature tokens, and use the existing ledger/TEMP/refinement checks. Metadata-only CIF exports are not structures and must never be delivered as final CIFs.
- For users without crystallographic training, explain the current stage, what is unresolved, who will handle it, and which final files exist in the customer's selected language (English for this edition, unless requested otherwise). Keep technical logs expandable/separate. The agent diagnoses software/scientific handoffs; do not ask users to supply a space group, restraints or SMILES they do not know. See [beginner reliability](beginner-reliability.md).

## Normal execution

1. Read the installed release/profile. If it explicitly provides `project_preferences`, verify its hash and read the applicable user convention, retaining the policy used for this job. Use `runtime_capabilities.py --profile PROFILE.json` and the [environment guide](portable-environment.md) to identify missing dependencies by feature. `probe_environment.py` inventories native software; file presence alone does not prove execution. Build a profile on each machine instead of copying machine-specific paths.
2. Accept the single questionnaire with `intake_once.py accept`; its output includes a frozen intake record, confirmed specimen metadata and an autorun configuration. For normal jobs use `crystal_autorun.py run --config JOB.json --output NEW_RUN`. It chains fresh solving → graph/H matching → local finishing → authorized delivery. It does not invent missing chemistry or select a space group solely by R.
3. The scripted initializer currently supports original HKL/P4P. Read [P4P dialect and native-input checks](p4p-native-input.md) for Rigaku/SAINT temperature provenance, optional SAINGL, complete hexagonal Laue operations and mechanical SHELX preflight. Never infer the temperature unit from its magnitude. Other allowed input formats use the explicit [workflow](workflow.md), `inspect_case.py`, `setup_job.py` and `run_crystal_stage.py`; do not silently fabricate prerequisites. Detailed commands are in [scripted pipeline](scripted-pipeline.md) and [automatic dispatch](automatic-dispatch.md).
4. For a complete 2D graph, use `crystal_pipeline.py match` and [graph matching](graph-matching.md); generate H plans using [hydrogen rules](hydrogen-and-report-rules.md). Uncertain charge, protonation, atom mapping or disorder returns a review packet. Geometric H generation must still pass refinement, contacts/residual and AB review. Do not copy an older H scheme.
5. For bounded, supported chemistry use `autofinish`; otherwise supply a documented scientific review to `finish` / `routine_finish.py`. Both retain weight-stability, model/data pairing, occupancy, [consistency](routine-consistency-checks.md) and local PLATON checks. Same-named trials cannot overwrite prepared inputs. Keep changed and unchanged AB instances visible with `compare_ab_alerts.py`.
   Final completion applies [element-wise atom numbering](final-atom-numbering.md) before validation and reports. Preserve native atom order, PART/AFIX and all atom references; retain the old/new label map. Unsupported or ambiguous naming needs review. CIF atom/aniso rows and both Word tables share element/numeric order; regenerate native outputs and validation after label changes.
6. Upload permission gates the network stage, not local refinement. An undecided upload choice allows local finishing to proceed. After existing/new authorization is recorded, resume the sealed checkpoint without solving or refining again. A changed model, notes, config or code invalidates the old ready checkpoint. Do not replay an uncertain submission. `iucr_validation.py recover --directory OFFICIAL_DIR` only retrieves already-created report URLs and verifies their association with the frozen submitted CIF.
7. A CIF or a successful SHELXL process is an intermediate result. For a manually prepared current candidate, use `complete_candidate.py` (project launcher: `complete`) after documenting the current chemistry/H review; it chains a preserved continuation, weights, AB checks, authorized official validation and both Word reports. Use [completion checks](delivery-completion.md); run `delivery_contract.py` before claiming full delivery. For direct local checking use `platon_check.py` / `platon-check`, which waits for complete reports and records the actual rule version. An absent external `check.def`, an empty initial report or a returned shell command does not prove a missing-rule failure: modern PLATON has embedded rules. Record explicit native errors only. See [PLATON and PDF reliability](platon-and-pdf-reliability.md). A confirmed local availability failure does not by itself block authorized official validation. Unresolved AB can accompany provisional diagnostic reports but never imply scientific acceptance.
8. Final customer copies belong in **`<original specimen data folder>/Cairystal`**. The finalization scripts copy the exact checked files there, verify hashes and return `customer_notice` plus four `customer_delivery.files` paths. Repeat runs use a new dated subfolder inside `Cairystal`, preserving existing results. For an intermediate candidate supply `complete --data-dir ORIGINAL_DATA_FOLDER`; never infer the customer folder from a temporary refinement directory. Tell the customer the exact returned save location at completion. See [customer delivery](customer-delivery.md) for recovery or a read-only input scope.

For every complete crystal solution/refinement job, the final user-facing answer must provide **four separate clickable file links**: **final CIF**, **IUCr_checkCIF.pdf**, **Chinese crystallographic Word**, and **English crystallographic Word**. Use the exact final CIF validated by that PDF, and generate both Word files from the same final model. A folder, dashboard, ZIP or Markdown report does not replace these four direct links. If any item is unavailable, name it and the reason, label delivery incomplete, and do not fabricate a final file. Final delivery retains the exact validated CIF and paired native files, **IUCr_checkCIF.pdf**, **Chinese and English Word**, and separate complete audit logs. Report-rendering PDFs are internal QA only. `autofinish` may seal after [measured automatic QA](automatic-report-review.md), explicitly without claiming visual inspection; manual finalization requires actual page review. Report prose stays concise and bilingual, not English execution logs pasted into the Chinese document.

After final report checks, the delivery scripts generate and seal an offline [interactive structure viewer](interactive-structure-viewer.md), with element colours/legend, per-PART filters, atom information and bounded symmetry assembly. Finalization requests a browser window by default. Keep the HTML as a supplemental deliverable alongside the four required files; show its link. If the host cannot open it, use its supported file/browser tool to show the returned path. Respect explicit headless/batch opt-outs and avoid duplicate tabs. Viewer failures are recorded separately and must not conceal valid reports or imply scientific failure/success.

## Select the relevant diagnostic reference

| Situation | Guidance and executable route |
|---|---|
| Missing experimental parameters; B196/TEMP | [Metadata preflight](experimental-metadata-preflight.md), [ledger/synchronization](metadata-and-disorder-comparison.md), [temperature](temperature-synchronization.md). Use [bounded project-side inspection](project-metadata-companions.md) for permitted metacif/phil/PCF/cif_od/P4P/logs; retain source lines, temperature/device scope and HKL-lineage conflicts and repeat native refinement after TEMP changes. |
| A/B and numerical convergence | [A/B playbook](ab-alert-action-playbook.md), [nonconvergence](nonconvergence.md), [systematic errors](systematic-error-diagnostics.md). Diagnose exact findings before restraints, coordinate/H changes, weighting or justified OMIT comparisons. |
| Disorder, occupancy, anomalous ADPs or short bonds | [Disorder/occupancy](disorder-occupancy.md), [ADP model selection](adp-model-selection.md), [short bonds](short-bond-disorder-diagnosis.md), [accounting/restraints](restraint-and-accounting-audit.md). Use current-run atom packets and [bounded trials](atom-diagnostics-and-trials.md); compare geometry, ADPs, residuals, uncertainty, constraints and model complexity, not alert counts alone. |
| Common CF3, tert-butyl, alkyl-chain or solvent disorder | [Common-disorder scripts](common-disorder-automation.md): finishing handoffs include a read-only motif scan. `common_disorder.py prepare` generates density-supported, hash-bound ISO/ANI comparisons; `run` executes the preserved control and candidates with SHELXL/local PLATON. Existing H follow their parent/PART populations. Unsupported chemistry, special/partial sites or insufficient density returns explicit review reasons. Selection and normal official/bilingual completion are still required; no automatic final-model replacement. |
| Host reliable, diffuse solvent difficult | [SQUEEZE workflow](squeeze-workflow.md). When a reviewed host is reliable and the remaining difficulty is independent solvent, use `squeeze_request.py prepare` to generate one model-specific customer choice or reuse the saved choice; `respond` records it and `execute` runs the existing comparison without LLM calls. An optional preserved comparison, not automatic atom removal. Requires explicit host/solvent attribution and charge/composition review. Current native branch supports untwinned HKLF 4 with unscaled ABIN. Every refinement/export carries matching FAB; metadata, AB, authorized official validation and both Word reports remain required. |
| Uncertain chemistry/H or validation pairing | [Chemical model](chemical-model-and-density.md), [validation evidence](validation-evidence.md). Unknown values stay unknown; scripts do not manufacture scientific acceptance. |
| Local image/knowledge assistance | [Local image v2](local-image-v2.md), [case-derived triage](case-learning.md). Optional experimental capabilities; model availability and training overlap must be disclosed. Do not strip isotope labels or use protected historical cases during blind tests. |

Read compact `handoff.json` / `decision_packet.json` first, then only the referenced evidence. Reuse intake context before asking anything. Scientific decisions remain recorded hypotheses, and a newly emitted CIF is not automatically accepted.

## Attribution and portability

For Word typography, release updates/rollback and failure feedback read [updates and support](updates-and-support.md). Reports apply scientific italic/subscript notation without changing atom labels or CIF data. `support_report.py` creates local Chinese explanations and a minimal feedback ZIP for scientific review or execution errors; never automatically emails, uploads or includes crystal files in that ZIP. Show the returned diagnostic path on failure. Public email/WeChat are configured once in `assets/support_contact.json` and printed at report end. Preserve fixed versions for existing jobs when switching the current release.

Use a small Cairystal assistance footer in both Word reports and the ASCII comment `# Structure solution and refinement assisted by Cairystal.` in derived CIFs, applied before hashing/validation. Preserve actual SHELX/PLATON provenance and the original IUCr PDF; the credit is not authorship or endorsement. See [credit and provenance](credit-and-provenance.md).

For another agent/computer read [agent handoff](agent-handoff.md). Written knowledge, implemented code and scientifically validated scope are distinct. This skill is not neural-network retraining and does not guarantee equal performance across agents. The [detail map](skill-detail-map.md) retains further references; historical worked cases are optional learning material and excluded from blind solving.

For source releases or bundled installers, preserve [third-party notices](../THIRD_PARTY_NOTICES.md) and follow [redistribution guidance](redistribution-licenses.md). The Gemmi notice is version-specific and does not certify other dependencies.

## Native diagnostic and CIF lookup checks

For mixed positive/negative PART, BIND, moved parents or split-site H, use the [native restraint and H audit](part-hydrogen-native-audit.md). The generic connectivity diagnostic has documented limits; alert reduction does not establish correct solvent geometry. If existing CIF parameters appear missing in reports or metadata carry-forward fails, use the [CIF data-name case checks](cif-tag-case.md).

## Two-question initial intake

Read permitted, paired experiment records and reuse prior specimen answers before asking. Ask both information groups only if both are missing: (1) crystal colour, habit and three dimensions in mm, with an example and unknown option; (2) possible elements including solvent/counterions and an optional 2D image. Reuse recorded observations with provenance without re-asking or requiring confirmation of the same facts. Ask only missing fields or specific contradictory records. Use `intake-form --metadata-ledger` to generate the question plan described in one-time-intake.md. An uploaded image is not a validated chemical graph. Record and reuse upload authorization separately; silence is not consent.
