# 本地二维图辅助 第二实验版

保留稳定版及第一实验版。本版是对已知测试图片的回顾性工程改进，不是未见过图片的独立验证，也没有训练/微调 MolScribe。

## 单一入口

`diagram_assist.py run --config CONFIG.json --output NEW_DIRECTORY` 顺序执行全图 OCR、分区、片段 OCR、局部标签 OCR、4 视图 MolScribe 和一致性检查。配置必须显式提供 manifests、mol_python、ocr_python、checkpoint、ocr_models（路径及哈希）和 schema。模型、两种 Python 环境均在 D 盘；不修改全局环境。

清单只允许图片路径、SHA256、case_id、可能元素种类及模型校验信息。禁止把 SMILES/参考模型混入识别输入。每次输出到新目录，每阶段保留命令、输出、耗时和失败原因；每个阶段最多 900 秒，失败不自动重复。固定代码/模型/输入哈希，评分在预测封存后读取单独真值文件。

## 针对本次问题的规则

- 拆图以图像连通域和文字区域为依据。长标题/化学式注释单独记录；不根据名称反查结构。合并相交/包含的区域，避免断开的字母被当成第二个分子重复计数。数字计量单独保留，不能默认忽略。
- 每个分子片段采用原图、2 倍采样、两种二值化视图。要求至少 3/4 得到同一完整规范化图，且元素在使用者给定集合内。多视图来自同一模型，属于相关证据，不是独立概率或正确率保证。
- Cl/Cu 和电荷只可用该原子位置上的文字证据校正。局部 OCR 多次读取，Cl 中 l/I/1/斜线的歧义还要求像素中相应竖笔及元素集合支持。没有局部证据时不按高氯酸根模板、净电荷期望或邻近氧数强改。原始预测保持不变，另存逐原子更改及标签截图。
- OCR 框扩边以保留上标，键线碎片清理保留独立记录。OCR 也会漏字/误读，不能直接覆盖所有 MolScribe 标签。
- 仅在明确、独立的 H2O 文字、多次 OCR 与 H/O 同等字高及下标 2 的像素布局一致时，才用文字式生成水组分。绝不把一个孤立 O 原子默认补成水；不能把附着在骨架上的标签拆成自由水。水的晶体学氢取向仍交给后续专门流程。

## 自动继续的边界

`supported_transcription` 只表示文字和图像检查支持转写。`ready_for_refinement_trial` 还须满足现有 C/N/O/F/Cl 范围、完整中性组成、无未处理手性/同位素/水氢等前提；后续仍可能因衍射证据停止。其它情况生成带原图、裁切图和具体原因的 handoff.json。

`diagram_assist.py promote --analysis RUN/consensus/result.json --case-id ID --output NEW_PRIOR` 只为通过该前置门槛的条目生成带哈希的程序筛查记录。记录明确写 automatically_screened_chemical_prior，不伪称 AI/人已看图确认。`local_assist.py` 与 autorun 在每次使用时重新核验原图、裁切、预测、决策、代码和化学图。图像准备阶段没有外部 LLM 调用；存在疑问时由 agent 读紧凑异常包。

通过前置检查后，以新求解坐标执行原有元素匹配/加氢、精修、权重更新、占有率/热参数/差值密度、本地 PLATON、IUCr 官网、中英文 Word 和排版检查。绝不因图识别得分提高降低原有科学门槛。

## 测试报告应怎样表述

原 14 张控制图与 2 张真实截图原样复测。R 基图不作为完整分子真值；拼图的分子数、有效分子图和是否需要审核分开报告，不把可解析 SMILES 等同于正确结构。另加 Cu/Cl、羰基和水的对照图，检查误纠正。图像层转人工次数与后续科学复核次数要分别统计。精确 Token 和 AI 总耗时节省在无遥测时保持 null；不能把检索字符减少或程序 LLM 调用为零冒充所有 AI 开销减少。

## 复测暴露的问题与保守边界

第一轮新增对照揭示共同模式错误：四次神经预测仍可能一致地漏掉 O 或多出 C。因此小片段（不超过 4 个非氢原子，包括单原子离子）一律送图像审核，直至独立的原子/键像素核对通过另行验证。明确打印 H₂O 仍走单独的文字与像素证据规则。此边界只阻止误放行，不自动更改候选；不根据已知答案补 O、删 C 或硬改计量。保留第一轮全部输出及代码快照，第二轮重新执行并分别报告候选正确率和错误自动放行数。

新增 4 张对照已被用于发现并收紧此边界，因此也属于回顾性工程检查，不是未见样本的准确率估计。真实铜离子尚未完整自动转写；复杂截图只生成片段候选，仍须审核。

## 当前范围：不考虑同位素

按用户要求，暂不开发和测试同位素识别。已知同位素样例 img010 标为范围外，不参与当前准确率和 AI 接手数量统计；保留原始预测与历史全量统计。后续本批测试使用根目录 image_config_no_isotopes.json（19 张），不重写旧运行配置。新材料若明确带同位素标签，保留标记并注明范围外，不把同位素静默改成普通元素，也不为本项目继续投入同位素专门判断。水、普通 H、手性、元素、电荷、精修、A/B 和官网验证要求保持原样。
