# A/B 警告：原因、对照试验与接受条件

适用：PLAT080、934、939、919、430、306、234、242、420。这是不含案例身份、参考模型或坐标的通用处理分支，可在授权的盲测内使用。按代码识别问题，级别可能随数值和验证版本改变，不只匹配某个固定的 A/B 字母。

若是 PLAT920–928 的 CIF/FCF 统计或差值密度不一致，以及 PLAT910–912 的缺失反射，先进入 [验证证据分流](validation-evidence.md#cif-and-structure-factor-consistency-workflow)，区分文件配套、模型复算和数据处理阶段，再决定是否需要改模型。

## 共用流程

1. 固定修改前版本：INS/RES/HKL/CIF/FCF/LST、原验证报告、文件哈希、活动 WGHT、空间群/设置、反射选择、PART/FVAR 和限制清单。
2. 读警告原文及对应原子/反射；把“已观察到的问题”“已确认原因”“待验证假设”分开。实验参数缺失另列，未知值不编造，也不因此停止其他模型诊断。
3. 每个编号分支尽量只改一类因素。比较模型时先保持数据和权重一致，权重更新另做分支。记录命令、版本、退出状态、耗时及失败方案。
4. 不只比较 A/B 总数：检查 R1、wR2、两类 S、shift/esd、NPD、差值密度、键长/电荷、占有率及不确定度、限制残差、参数数目和反射完整度。无法获得的量写 null 并说明原因。
5. 采用后生成配套 CIF/FCF 并重新验证；新增警告同样列入简表。只有新报告才能证明该文件的警告变化。正式交付按当前任务的上传授权完成 IUCr 官网含结构因子的验证；本地 PLATON 不能冒充官网报告。

A/B 是优先诊断队列，不是覆盖科学证据的评分函数。保留 `resolved_with_evidence`、`downgraded_requires_review`、`explained_requires_review`、`unresolved` 等区分；字母降级不自动算原因已解决。当前用户不要求仅为 C 警告继续精修，但原报告和重要缺陷仍须保留。

已授权自主精修时，检查点可以是日志中的证据与决定，不必每个局部试验都重复询问。任务禁令、盲测边界及冻结版本约定优先。本文是操作指导，不代表现有脚本已经实现无人值守自动修复。

<a id="plat080"></a>
## 080：先找移动参数，再决定如何约束

- 从最终 LST 的逐轮 shift/esd、最大移动参数及相关矩阵定位问题：坐标、Uij、FVAR、甲基转角还是其他全局参数。若正常下降且模型合理，可以继续有限次不变模型迭代；振荡则改变诊断，不无限重复。
- 已有合理方向、但旋转自由度缺少数据支持的氢组，可单独试 `AFIX 3`。它是 m=0、n=3：**不生成或重新理想化 H 位置**，坐标随前一个非 riding 母原子作同样位移；它本身不固定 SOF 或 U。已有错误方向不会因此变正确。
- 先校对 D–H 键长、方向、母原子顺序、PART/SOF 与 Uiso 关系；关闭组用 `AFIX 0`。水氢优先用差值图结合化学几何定位；改成 riding 后说明方向是约束的，不能声称自由精修确定了方向。
- 只有明确的弱定/相关参数、已支持的几何或必要对称关系，才试固定少数坐标；记录原值、固定原因和被移除自由度。SHELXL 参数“加 10”编码须逐字段核验，不得对所有坐标盲加，也不得破坏特殊位置。一般由程序施加特殊位置约束，极性空间群的原点处理不应随意靠固定一个原子代替。
- 在可行时做释放固定或弱化约束的对照。保留最终固定参数清单，不给它们伪造精度。多原子 NPD、错误键连或全局异常时先重查模型/对称性；冻结错误骨架、`DAMP 0 0` 或零循环不算解决不收敛。

依据：[IUCr PLAT080](https://journals.iucr.org/services/cif/checking/PLAT080.html)、[SHELXL AFIX 与原子参数编码](https://shelx.uni-goettingen.de/shelxl_html.php)。

## 934 / 919：小数量异常反射的 OMIT 对照

用户偏好（2026-10-26）：不超过 20 个异常反射时优先尝试 OMIT，避免反复停在建议上。落实为**核对后直接建立有记录的对照分支**，不是从原始 HKL 删除行。“≤20”是本项目的试验规模偏好，不是通用科学阈值，也不自动保证完整度不受影响。

两项检查不可混同：

- **934**：观测与计算强度差超过 10 sigmaW；sigmaW = sqrt(1/w)，不是必然等于输入 sigma(I)。先列出带符号差值、活动权重及实际使用的阈值。权重变化会改变计数，较少异常点不必然表示模型变对了。
- **919**：针对很低角度（官方说明为 theta < 3°）、观测强度异常偏低的束挡相关筛查。单凭该报告不能诊断“过曝”。读取配套 CKF/LST 的反射表，并核验实际版本的权重定义；不把它当成所有正负 >10σ 异常点的同义词。

执行顺序：

1. 核对 CIF/FCF/模型配对、hkl 设置/合并规则、Fo²/Fc²/sigma(I)/权重；区分测量记录数、独立反射数及重复报告的同一索引。919 与 934 重复索引去重计数。记录负强度，不一概删除。
2. 先排查明显未完成的模型、错误元素/占有率、孪晶、漏溶剂或缩放错误。如果异常遍布数据或模型明显错误，先修模型；不能反复用新 Fc 挑差点、累计删到低于 20 个。
3. 审查已有束挡/过载标志、原始帧或积分日志。未提供这些文件不阻止已授权的**敏感性试验**，但记录物理原因未确认，不宣称“已修正曝光”。不要为此越过盲测读取边界。
4. 对经核对且数量 ≤20 的候选列表，保存完整数据基线，在新 INS 中逐项加入明确的 `OMIT h k l`；不使用整体 sigma 或分辨率切除代替这份列表。对 HKLF 5/孪晶先核验当前版本的索引和分量语义，不盲套 HKLF 4 规则。超过 20 个时停止这条快捷分支，转为整体数据/模型诊断。
5. 同时报告省略数/独立数据数、总体及低角度分区完整度、可用 Friedel 配对变化；若不能计算就记为未知，不声称影响可忽略。少量低角度强反射仍可能影响尺度、消光或绝对结构。
6. 先固定原权重精修对照，再单列必要的权重更新。比较保留反射上的拟合，同时检查完整数据基线和被省略点的残差、ADP、占有率、几何及差值图。减少数据后 R 值下降不是独立的成功证据。
7. 按本项目偏好，常规 HKLF 4 的固定清单通过本地复算后，直接用 OMIT 工作版继续收尾。核对 FCF 中减少的正好是这些指数、完整度、占有率、收敛及剩余警告。已有局部键长限制轻度冲突可随报告保留。CIF 和两种语言的方法栏写明指数、带符号加权残差、排除数和仪器原因的证据。没有原始帧时记录仪器原因未确定。保留全数据版本供复核。

每项记录至少包含 `h,k,l,component,theta,Fo2,Fc2,sigma_I,sigmaW,source_alert,evidence,reason_confirmed,action`。某字段不可获得时写 null。

依据：[IUCr PLAT934](https://journals.iucr.org/services/cif/checking/PLAT934.html)、[IUCr PLAT919](https://journals.iucr.org/services/cif/checking/PLAT919.html)。

<a id="plat939"></a>
## 939：分别报告两种 S，不能只追 GoF = 1

PLAT939 的 S 仅依据提供的 sigma(I)，而 SHELXL 的 GoF 使用实际精修权重。后者接近 1，前者仍可能很大；异常强度和过小的不确定度等需要另外诊断。这不是“忘了调整 WGHT”的直接证据。

记录 `shelxl_gof`、`platon_939_s`、活动 `WGHT`、RES 末尾建议值及强度/分辨率分区残差。先查看贡献最大的反射，并与 919/934 对照。模型基本合理后，才在独立分支采用 SHELXL 建议的权重，检查是否趋稳。不得通过改大原始 sigma(I)、编造误差或强行调权重令 939 消失。权重更新不能修复缺失电子密度或错误组成；低于 1 也可能提示当前权重不再适合更新后的模型。

依据：[IUCr PLAT939](https://journals.iucr.org/services/cif/checking/PLAT939.html)。

<a id="hydrogen-alerts"></a>
## 430 / 306 / 420：主动检查氢，但先确定化学身份

- **430（短 D···A）**：把漏氢、质子化及漏识别氢键放在优先检查项；查看完整基团、键级、电荷和对称相关原子。羧酸盐、配位桥连、无序替代位置等不自动需要补 H，不能把每个短 O···O 都改成水或羟基。必要时检查元素指认或重复原子。
- **306（孤立 O）**：主动尝试水分子解释和差值图搜 H，不以“有孤立 O”作为忽略检查的理由。先排除漏识别对称配位、其他含氧基团或错误元素。支持水后，选两个化学上合理的 H 方向，结合差值密度、对称展开的受体及接触检查；明确哪些位置来自密度、哪些来自几何假设。采用合理 O–H/H···H 限制或 riding 对照，核验水的占有率、特殊位置及 H 总数。
- **420（D–H 无合适受体）**：已有 H 时优先重定向，不重复补一个 H。尤其检查 OH 的计算方向是否反了，以及受体是否在邻近晶胞。先选择有依据的位置，再用 AFIX 3 保持，不是先固定再任意挪到最近的受体。NH/NH2 并非一定有可识别受体，不能只为通过氢键筛查硬造方向。
- 每次添加/移动 H 后检查 D–H、H···H、H···A、D···A、角度、正负差值密度、PART/SOF、氢的 Uiso 及组分化学式。新增 417/420 等接触/方向警告、明显负密度或强限制依赖时，不因原来的 306/430 消失就采用。
- 若水身份合理但 H 方向不唯一，保留可信候选及失败记录，说明未定位氢/方向不确定；不能将猜测位置报告成已观测位置。

依据：[IUCr PLAT430](https://journals.iucr.org/services/cif/checking/PLAT430.html)、[PLAT306](https://journals.iucr.org/services/cif/checking/PLAT306.html)、[PLAT420](https://journals.iucr.org/services/cif/checking/PLAT420.html)。

<a id="adp-alerts"></a>
## 234 / 242：先核对模型，再选择局部限制

- **234（Hirshfeld 刚性键检验）**针对成键方向的位移分量差异，不等同于 Ueq 比值。先查散射类型、占有率、未处理无序和数据误差。若局部基团可靠而 ADP 弱定，可以优先试成键相关的 RIGU/DELU，或有理由的邻近原子 SIMU。少数异常原子并不自动证明应加限制。
- 限制范围应明确到原子/片段和实际成对列表；检查跨 PART、特殊位置、重复或冲突限制。RIGU 不是把所有 Uij 设成相等，SIMU 也不等同于 RIGU；ISO 原子不能靠 RIGU 获得各向异性信息。记录强度/s.u.，做弱化或取消限制的对照，检查最终 LST 的限制残差。B 变 C 而在弱化后恢复，标记为限制敏感，不宣称原因已消除。
- **242（相邻原子相比 Ueq 偏低）**：先核对 SFAC 顺序、原子实际类型和允许元素，名字以 C/N/O 开头不是散射类型的证据。检查本原子 Ueq 和每个邻居，区分本位点偏低与末端/无序邻居偏大。结合键长、价态、电荷、残差及占有率比较有化学依据的替代类型；不能只用一个 Ueq 比值决定换元素。
- 保持比较条件一致；不得为追平邻居而无依据抬高本原子的 U，或用 SIMU 掩盖错误元素/无序。候选即使零 A/B，若几何不成立、限制严重冲突或电子密度不支持，仍不采用。

依据：[IUCr PLAT234](https://journals.iucr.org/services/cif/checking/PLAT234.html)、[PLAT242](https://journals.iucr.org/services/cif/checking/PLAT242.html)、[SHELXL 限制指令](https://shelx.uni-goettingen.de/shelxl_html.php)。

## 简表与方法验证

每个晶体显示：匿名编号、模型相关 A/B、数据相关 A/B、另列的元数据缺失、涉及原子/反射、已试方法、修改前后值、接受/拒绝理由、当前版本及报告链接。未重新验证写“待验证”，不能填零。保留现有验证覆盖限制和缺失参数，不把没有读取答案的候选称为正确结构。

复核指导规则时至少覆盖：旋转 H 振荡与错误骨架的区别；带 939 但加权 GoF 近 1；919/934 重复索引和 20/21 点边界；低角度完整度未知；补水氢产生碰撞；430 的非质子化配位氧；234 对限制敏感；242 由高 U 邻居造成；420 已有 H 不应重复添加。文档静态检查只验证规则存在/链接有效，不能冒称这些科学修复已全部实测成功。
