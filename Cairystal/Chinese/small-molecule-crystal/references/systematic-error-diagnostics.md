# 系统误差、消光与整体热参数诊断

EXTI/SWAT 并用、LIST 设置、字面重复 OMIT 已由 [常规检查脚本](routine-consistency-checks.md)识别。消光病因、整体 ADP、分组方差与校正效果仍按本页诊断，不能自动从指令清单得出结论。

用于强低角反射成批偏离、PLAT031、PLAT250 或加权后仍有分组趋势的情况。本文不含历史模型、样本身份或坐标，可用于盲测。常规单原子 ADP 与异常反射处理仍见 [ADP 模型选择](adp-model-selection.md)、[A/B 流程](ab-alert-action-playbook.md)。本页是诊断规则，不是已实现的自动修复器。

## 1. 先区分两种“消光”

| 情况 | 应查的证据 | 处理方向 |
|---|---|---|
| 系统消光：中心化、螺旋轴、滑移面规定某些 hkl 的结构因子为零 | 允许/禁戒反射族、强度与不确定度、设置与指标变换；确认上游是否已删去禁戒反射 | 重新评估晶格/空间群与积分问题；不是加 EXTI |
| 强反射受消光效应影响：实际强度偏离运动学近似 | 强度与分辨率分组的系统偏差、EXTI 参数及 s.u.、模型/尺度相关性 | 在主要非氢骨架完整后，单独比较有/无 EXTI 的精修 |

空间群含螺旋轴不是启用 EXTI 的依据。禁戒反射不存在也不能从已筛选的 HKL 反推“空间群已证实”。SHELXL 的 EXTI 是经验性校正；不能据其数值直接反演晶体完美程度、微结构尺寸或曝光时间。

### 有/无 EXTI 的对照步骤

1. 封存当前 RES/HKL/LST/FCF 及哈希；检查大部分强度偏差是否集中在强低角区。记录 LST 方差分析的分组数、GooF、K，以及最大差异反射；统一其归一化和合并定义。K 明显偏低可提示 Fo² 相对 Fc² 不足，但不是病因鉴定。
2. 并列排查尺度、吸收、探测器饱和、束挡、重叠、遗漏原子/溶剂、孪晶。只有 HKL 时通常不能确认曝光或饱和；缺少原始帧就记录“原因未区分”。
3. 保持空间群、原子模型、HKL、OMIT 和初始 WGHT 相同，建立只增加 EXTI 的候选。保留无 EXTI 基线；不要同时删点、改无序或加一批限制。
4. 比较 EXTI 值及 s.u.、相关性、最大 shift/s.u.、各强度/分辨率组的偏差、R1/wR2、差值图、坐标与 ADP 稳定性。整体 R 略降而关键参数剧变或局部残差未改善，不足以采用候选。
5. PLAT031 检查 EXTI 的显著性；官网说明给出约 3.33 s.u. 的提示界限。数值不显著、卡在边界或不收敛时，保留去掉 EXTI 后重新精修的版本。超过阈值仍需前述物理证据，不能自动接受。
6. EXTI 与 SWAT 处理不同问题，SHELXL 不允许两者同时精修。不得靠切换两者追求最小 R。若采用校正，必须重新生成同版本 CIF/FCF 和验证报告，检查下游程序对校正后结构因子的解释，见 [配套文件验证](validation-evidence.md)。

## 2. GoF 接近 1 后仍要看分组趋势

区分三个层级：积分/合并阶段的 σ(I) 误差模型；结构模型对衍射强度的拟合；精修 WGHT 对残差的加权。上游等效反射的 χ² 与精修 GoF 不是同一个统计量。改变 WGHT 不会重新积分或修复吸收。

- 同时保存按强度、按分辨率分组的统计，不能仅保存整体 GoF。若有上游日志，再检查帧/批次/方向依赖。某些组偏大、其他组偏小可以相互抵消。
- 检查 LST 的组界与列顺序，再称为“最强”“低角”或“高角”。建议权重改善强度方向的方差分布，不保证分辨率趋势也消失。
- 尽量先完成主要原子模型与合理 ADP，再做有界的权重迭代。持续出现系统趋势时返回模型和数据质量诊断；不要无限更新 WGHT 直到整体数字满意。
- 保留弱/负观测强度；不能以提高 I/σ、降低 R 或接近 GoF=1 为唯一理由截去高角区。分辨率变化必须记录独立反射数、完整度、参数支持和残差变化，并标记与原模型比较的数据集已改变。
- 只有已经合并的 HKL 时，不能声称复核过批次一致性、原始等效观测 χ² 或重新优化过探测器误差模型。

## 3. PLAT250：整体方向性，区别于单个椭球拉长

PLAT250 检查所选残基/不对称单元的平均 U 张量主轴比例。许多椭球同向伸长可能提示数据系统误差、模型问题，也可能含真实的方向性运动；该警告本身不能区分原因。它不是“某一个碳椭球不够圆”的同义词。

1. 明确被统计的残基与原子集、ANI/ISO、PART 和占有率；记录是否包含弱次要无序组分。先区分个别原子异常与跨多个不相连片段的一致方向。
2. 若计算方向/特征值，先把所有 ADP 依照晶胞度量转换到同一正交坐标系；不得直接平均不同基底下的 Uij。说明选择和加权方式，不把自定义统计冒充 PLATON 的原始指标。
3. 局部异常先查元素、占有率、无序连接、缺氢与相邻原子；整体异常优先查吸收/尺度、方向性分辨率覆盖、晶体移动、孪晶和对称性假设。按可用数据逐项保留或排除，不从椭球图直接宣布吸收失败。
4. 若局部无序有密度证据，可比较分裂模型或有依据的局部限制；若怀疑整体数据问题，则优先查上游记录。全分子 ISOR/SIMU 或把所有原子改成 ISO，可能消除表现而掩盖共同原因，不能当作默认修复。
5. 记录限制强度变化的敏感性、真实键长/接触、残差与参数稳定性。合理方向性运动可保留并解释；未解决的系统问题即使 A/B 消失也必须出现在局限中。
