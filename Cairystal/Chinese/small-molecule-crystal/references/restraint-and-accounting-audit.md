# 几何限制、晶胞内容与资料纠错

简单公式/Mr、晶胞体积、密度、F(000) 初筛及指令冲突已有 [只读脚本](routine-consistency-checks.md)。SAME 化学映射、CHIV/FLAT 物理判断及变温结构对应仍需按本页复核。

用于 SAME 映射不清、无序几何受限但仍不合理、报告数值矛盾或从旧教程学习的场景。本文不包含样本坐标、身份或占有率答案；是诊断知识，不新增自动修复程序。已有 [占有率规则](disorder-occupancy.md)、[化学判断](chemical-model-and-density.md) 和 [报表一致性](report-model-consistency.md) 继续适用。

## 1. SAME 应先审计对应关系，再审计几何

先建立对应表：源原子、目标原子、元素、邻接环境、组分/残基、对称操作。按化学等价性配对，不能按标签数字或空间距离自动配对两个无序构象。C/N/O 互换、环顺序颠倒及插入的无关原子都可能生成错误的几何限制。

普通 SAME 把指令列出的非氢原子序列，与指令后相同数量的非氢原子逐一对应，对连接表中的 1,2 和 1,3 距离施加相似性限制。它不强制整个分子的扭转角、环起伏或空间构象相同。

执行前后均检查：

1. 指令实际位置、非氢原子次序、`>`/`<` 展开的标签范围、RESI 与 PART、共享原子及对称邻居；尤其注意范围内是否夹入了别的片段。
2. 核对生成的连接表。距离阈值产生的“键”不一定是化学键；缺键或错键会影响生成的 1,2/1,3 限制。必要时改用明确原子对的 SADI/DFIX/DANG，保留理由。
3. 查看 LST 中实际限制和偏差，不只统计 INS 中有几条命令。可在单独诊断副本中利用无原子列表的 SADI 导出 SAME 对应的 SADI；末尾导出内容不是自动启用的新精修指令。
4. 对两个组分分别核对几何和共存接触，避免把互斥组分的近接当作共价键。SAME 改善键长也不能证明次要组分被独立观察到。
5. 限制强度、自由度、占有率/U 相关性和差值密度一起比较。强限制得到的漂亮键长属于模型先验，不能在报告中称为独立精确测量。

**版本区别：**现代 SHELXL 的 `SAME_<残基名称>` 可作用于同名残基，和普通 SAME / `SAME_<残基编号>` 的位置规则不同。旧教程不能直接套入当前版本；使用相应官方说明并核对实际展开结果。不要仅凭文件中出现 SAME 就声称所有期望组分都受约束。

**水氢例外：**SAME 忽略 H。`SAME_WAT OW HW1 HW2` 不能作为已经对水的 O–H/H···H 几何施加限制的证据。水氢位置须由密度、氢键、占有率与对称性支持；必要时用明确 O–H 和 H···H 原子对的 DFIX/DANG/SADI，选择与实验/精修方式一致的目标。不能把手册示例距离当作所有数据的通用实测值。

## 2. CHIV、FLAT 与手性证据的区别

- CHIV 约束的是有符号体积；通常用于具有三个非氢连接邻居的中心。先检查连接表与实际适用条件，不对任意四配位金属或全部 N 一键应用。
- 当前 SHELXL 的体积定义是三条键矢量的标量三重积，单位 Å³，相当于对应几何四面体体积的六倍并带符号；不能再除以六后作为同一目标输入。符号由邻居标签的 ASCII 排序确定，不等同于 R/S。重命名原子后必须重查符号。
- `CHIV 0` 表示平面性倾向。化学上可锥形的中心不能仅为了收敛强压成平面；需要保持锥形/既知手性时，目标和符号要有独立依据。未知手性不能通过施加 CHIV 自己“证明”。
- FLAT 是一组原子的平面性限制。芳环等有化学依据的局部平面可考虑；THF、饱和环、多个可旋转芳环组成的整分子不应自动压平。CHIV/FLAT 的强度参数不能按键长限制的单位直接照搬。
- 记录限制的目标、s.u.、原子集合、实际偏差和敏感性。绝对结构仍按衍射及其他独立证据评估；添加手性先验不使 Flack 自动成为可靠结论。

本节针对 X 射线常规用法；中子数据、特殊连接设置及更复杂的几何要按实际软件版本另行检查。

## 3. 从晶胞内容独立核算报表

已有表格即使来自 SI、已发表文章或已解模型，也只是一项待核对的来源。先确定公式的单位是化学式单元、完整分子还是不对称单元；显式模型与掩膜溶剂分开记账。

核算顺序：

1. 从对称轨道、占有率和组分共存规则计算各元素的**每晶胞**数量；不能按坐标表的行数计数。对照 `Z × 化学式` 与 SFAC/UNIT，各自保留来源。
2. 独立由元素计数求 Mr，并核查报表 Mr；未知溶剂、同位素或非整比成分须说明，不能强行凑公式。
3. 对常规质量密度，`ρ_calc (g·cm⁻³) = 1.66053906660 × Z × Mr / V(Å³)`。没有独立的密度实验记录时，不能称为实测密度。
4. 对常规中性原子电子计数，`F(000)_electron = Σ(每晶胞元素数 × 原子序数)`。若软件使用带色散项/特殊散射因子的定义或包含溶剂贡献，先明确 F(000) 约定；不要用简单电子计数覆盖不同定义的字段。
5. 记录每个原始值、计算值、差异及可能的舍入影响。超出解释范围时标记冲突；不能通过只改 Z、密度或 F(000) 中的一项来消警告。回查同一模型的 CIF、RES、处理记录与公式来源。
6. 表格复制错列、不同温度的数据混用、H/溶剂漏记、不同公式/Z 归一化均是候选原因，未经核对不能认定是哪一种。修正后重新生成中英文表和模型一致性记录。

这些关系是内部一致性检查；公式、Z、密度、F(000) 相互匹配仍不能证明化学身份、元素指认或无序正确。不同公式/Z 的等比例表示也可能给出相同晶胞质量。

## 4. 变温结构和“单斜角等于 90°”

比较两个温度时先配对各自实验与模型，核对晶胞基矢、空间群设置、原点和可能的超胞变换。a/b/c 列名相同不保证是同一物理方向；轴交换、约化胞或倍胞会制造假“跳变”。

优先记录变换关系、体积/公式单元、数据分辨率与完整度、各温度采用的几何/ADP限制。未确定结构对应关系前，只报告观察到的差异；不能从 b 近乎减半就宣布相变，也不能用不同限制目标造成的键长变化作温度效应。

单斜结构可以具有偶然或近似正交的晶胞度量。PLAT181 是检查提示，不是“角度为 90° 就不允许单斜”的定理。检查晶胞精度、Laue 对称、强度等价性、系统消光、结构对称及孪晶候选；不能只因度量接近正交就强行升到正交空间群。

## 5. 教程内容的采纳与纠错

学习时保存“原主张—所需前提—核对依据—采用/修正/未采纳”的记录。经验指令和审稿回复不能直接变成无条件规则。

本次特别排除以下误用：把 EXTI 当作螺旋轴系统消光处理；把 PLAT250 只解释为单原子椭球形状；把单斜晶胞角度必须偏离 90° 当作硬性条件；将旧宏分子示例的截断、NCS 或 Rfree 操作默认移植到小分子。若确需留出验证集，必须在建模前固定并处理等价反射泄漏；反复用同一数据选模型后再声称“独立验证”不成立。
