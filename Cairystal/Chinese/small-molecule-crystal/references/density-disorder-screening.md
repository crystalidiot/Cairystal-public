# 差值密度引导的候选与分级筛选

本工具生成并比较假设，不自动认定无序或选择终稿。稳定版不替换；旧任务继续用原版本。

## 主线

1. 对当前成套 RES/CIF/HKL/FCF/LST/INS 做配对检查。先核对元素、缺氢、组成及对称位置，不把错误连接图当作可靠片段。
2. 按当前连接图识别 CF3、叔丁基、已证实的简单饱和链及身份有依据的常见溶剂。P/O 等非碳连接原子也可作为旋转锚点。
3. 取本轮 SHELXL `FMAP 2` 的 Q 峰，展开附近对称像。对有键轴的片段从峰位置计算转角；独立刚性片段用三个非共线点拟合旋转和平移。保留手性，只用正旋转。这里是**峰列表引导**，不是完整连续差值 Fourier 图优化；峰列表有截断和模型相位偏倚。
4. 至少两颗不同的替代峰支持新位置；大于五个原子的片段至少三颗。一个峰不能支撑两颗原子。排除严重近接触，合并等价末端排列。没有支持则返回 `insufficient_supported_density`，不强行拆分。
5. 默认每个片段最多四个候选、最多四个片段。先六轮 SHELXL 短筛，主分支各向异性、次分支各向同性（`MAJOR_ANI`；这是固定 A 分支，不会按精修后的占有率偷偷换名）。短筛 **A/B 为 null**，不是零；不收敛本身不直接淘汰。保留未入选候选及原因。
6. 每个片段默认选一个候选进入完整比较。入选分支都从相同基准重新开始，分别比较 ISO、ANI、MAJOR_ANI，默认各三十轮，另做同轮数未改对照。每个完整分支必须做 PLATON、文件配对、占有率、H/PART 一致性、分支塌缩、ADP、几何、差值密度与 A/B 对照。
7. 查看完整比较。低 R 不证明无序正确；新增非正定 ADP、失去占有率支持、近乎重合或新增模型 A/B 时不自动采纳。需要扩大短名单时，在新目录改 `finalists_per_site`，不篡改原试验。不得用短筛结果直接交付。
8. 经过科学复核后，仍按 `complete` 完成权重、确切最终 CIF 的官网 PDF 和中英文 Word。暂未解好的结构可以生成明确标注的诊断报告，不能标为已解决。

## 调用

在 skill 目录，用已配置的 Python：

```powershell
python -B scripts/toolbox.py run density-disorder -- prepare --baseline CURRENT_BUNDLE --output NEW_COMPARISON --profile LOCAL_PROFILE.json
python -B scripts/toolbox.py run density-disorder -- run --plan NEW_COMPARISON/plan.json
```

溶剂身份有用户信息或本轮化学证据时，显式附 `--possible-solvents dichloromethane`，并在任务审查记录中写来源和假设状态。不能只凭孤立原子数猜溶剂。`--site-ids` 可限定部位；`--settings` 提供 JSON。软件、代码、基准和线程设置在 plan 中记录并核对，配置改变应新建比较。

输出 `plan.json`、`screen/*/screen.json`、`full/*`、`comparison.json`；原 HKL 不改。短筛与完整比较耗时分开，官网和排版耗时另计。没有真实计量器时，不能把脚本内零 LLM 调用称为整次任务零 Token。

## 当前边界与实测教训

- 不自动处理已有 PART、特殊位置、未组装的跨胞片段、自由氢、柔性环构象、多键联合链构象，也不重新识别化学身份。
- 即使初始位点是一般位置，SHELXL 也可能把拆分原子移到特殊位置。完整比较结束后重新计算位点稳定子；出现这种迁移即标记 `split_atom_moved_to_special_position`，要求复核物理占有率、重数和对称连接。不能把特殊位上的 CIF 占有率直接当作整个次要组分比例，也不自动减半或加倍去消除警告。
- 苯环缺峰/断裂可能被几何图误看成链；没有明确 sp3 和 CH2/CH3 证据时交复核，不能套用链旋转。
- 两支对应的 1,2/1,3 距离用 SADI；CF3/叔丁基必须包含共享中心与末端的键长限制，不能遗漏中心键。限制只表达假设，不证明模型。
- 普通新主/次支可以比较混合 ADP；全 ISO 有时破坏主要组分的拟合，全 ANI 有时使次支过参数化。这些须用同数据实测，不预设赢家。
- 短筛有额外成本。只有候选足够多且后续完整验证确实减少，才可能提速；相对旧版较少候选的算法不保证更快。
- 开发数据重用只叫“参考答案隔离重解析”，不称未见测试。测试代码使用人工几何；公开包不包含真实晶体坐标或 HKL。
