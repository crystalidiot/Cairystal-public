# Cairystal 交接说明

本包版本：`delivery_state_sync_20261126_01`。使用无需依赖作者的聊天记录。先读 `START_HERE.md` 和 `INSTALL.md`，中文入口 `Chinese/small-molecule-crystal/SKILL.md`，英文入口 `English/small-molecule-crystal/SKILL.md`。两版代码功能相同，选一种即可。

## 给接手助手的话

> 请阅读本包 INSTALL.md、所选语言 SKILL.md 和 references/flow-handoffs.md。先校验文件和本机依赖，生成本机 profile；不要照抄作者电脑路径。常规操作直接调用统一工具，支持的结果自动接回主线；元素、氢、占有率或无序解释不确定时依据本次数据比较候选。只集中询问无法从同样品记录获得的信息。不要读取旧模型作为独立解析的答案。保留原始 HKL、前后模型、真实命令和耗时。沿用本例已有适用授权；官网回执必须匹配最终 CIF。完成后给出原始数据目录 Cairystal 下最终 CIF、IUCr_checkCIF.pdf、中文 Word、英文 Word及剩余问题。

## 本版做了什么

- 修复采用固定清单 OMIT 结果后，任务摘要仍读取旧验证目录的问题。
- `resume-delivery` 接上自动报告 QA 和客户目录发布。报告已经生成时续接检查，不重解结构、不再提交 CIF。
- 新任务保存原始数据目录；历史任务没有目录字段时由助手用 `--data-dir` 明确指定，不猜测中间目录。
- 清理自动 OMIT 与“所有对照都停下来”的冲突文档；保留科学歧义和报告异常的具体复核入口。

仍有62个统一工具；在所选目录运行 `python -B cairystal.py guide`、`list`、`describe 工具名`。脚本不调用模型 API。整体任务仍可能需要 AI，不能把脚本 AI 调用数0说成全任务 Token为0。

## 安装和运行边界

这是 Windows x64 / Python 3.12 工作流，需要使用者合法安装 SHELXT/SHELXL、PLATON（规则数据文件也须可用），以及 Word 或 LibreOffice、Poppler。SHELXD、二维图识别等按任务选配。本包不包含晶体学软件安装程序、模型权重、第三方课件或真实样品数据。

主线是输入与实验参数 → 求解与初解检查 → 元素/氢及精修 → 权重 → 本地AB与工具对照 → 选定模型 → 官网checkCIF → 中英文Word和QA → 客户文件夹。工具缺少确定依据时记录并交给助手；低R或零AB不能单独证明结构正确。

新版放入新目录，正在运行的任务继续使用创建它的版本，不替换其脚本。需对外上传时核对本例授权和目标；未知的提交结果不能自动重新提交。

按 INSTALL.md 完成包校验、profile、doctor和离线验收。然后选用有权使用的样品，实际检查四份交付物。WorkBuddy、飞书宿主的完整实际解析尚未在本次测试，不能宣称已通过这些平台认证。平台接入见 `跨平台使用.md`。
